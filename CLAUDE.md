# CLAUDE.md

Follow these rules for all coding tasks:

1. Do not guess. Ask if anything is unclear.
2. Make the smallest possible change.
3. Do not make unrelated refactors or cleanup.
4. Do not add unrequested abstractions, options, or features.
5. Match existing code style.
6. Explain assumptions briefly.
7. Define how you will verify success.
8. For bug fixes, reproduce the issue and verify the fix with tests when practical.
